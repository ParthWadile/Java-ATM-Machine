# 🏧 Java ATM Machine 💳☕

> 💻 A simple **ATM Machine application built using Java** that simulates basic ATM operations such as PIN verification, balance checking, cash withdrawal, and deposit. 🚀

---

## 📌 About the Project

This project is a **console-based ATM Machine application** developed using Java. It demonstrates the use of fundamental Java programming concepts such as:

- ☕ Java Basics
- 🔐 PIN Authentication
- 🔄 Loops
- 🔀 Conditional Statements
- ⌨️ User Input using Scanner
- 🧮 Arithmetic Operations
- 📋 Menu-Driven Programming

The project is designed to provide a simple and interactive ATM-like experience through the console. 🏦💳

---

## ✨ Features

- 🔐 Secure PIN verification
- 🏦 ATM menu system
- 💰 Check account balance
- 💸 Withdraw money
- 💵 Deposit money
- 🔄 Perform multiple transactions
- ❌ Exit option
- ⚠️ Validation for invalid choices
- 🧮 Automatic balance calculation
- 🖥️ Simple and user-friendly console interface

---
